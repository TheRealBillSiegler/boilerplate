# Templates hub

Choose a template. See what's available. Jump to deeper docs when you need them.

## Choose a template

| Template | Extends | Use when | Docs |
|----------|---------|----------|------|
| **`project`** | — | Standard Python project (library, service, internal tool). Balanced defaults: src layout, tests, toolchain. | [Guide](project.md) |
| **`streamlit`** | `project` | Streamlit data or dashboard app. Project plus Streamlit UI & container assets. | [Guide](streamlit/index.md) · [Containers](streamlit/deployment/containers/index.md) |

List locally: `boilerplate list`

Authoring a custom template? See the [Authoring guide](authoring.md) and [Composition guide](composition.md); when a template needs a breaking change, [Versioning and migration](versioning.md) sets the rules and the [Migration guide template](migration-guide-template.md) documents it.

## Where next

Most users start with `project`; need an interactive UI? pick `streamlit`. Exploring custom scaffolds later—read the authoring guide. Continue to [Quickstart](../quickstart.md) or return [Home](../index.md).
