# Templates hub

Choose a template. See what's available. Jump to deeper docs when you need them.

## Choose a template

| Template | Extends | Description | Docs |
|----------|---------|----------|------|
| **`project`** | — | A general-purpose Python project, with its tools configured. | [Guide](project.md) |
| **`streamlit`** | `project` | A Streamlit app, built on the general-purpose template. | [Guide](streamlit/index.md) · [Containers](streamlit/deployment/containers/index.md) |

List locally: `boilerplate list`

Authoring a custom template? See the [Authoring guide](authoring.md) and [Composition guide](composition.md); when a template needs a breaking change, [Versioning and migration](versioning.md) sets the rules and the [Migration guide template](migration-guide-template.md) documents it.

## Where next

Most users start with `project`; need a Streamlit app? pick `streamlit`. Exploring custom scaffolds later—read the authoring guide. Composing or updating a project without the CLI? See [compose and update with plain Copier](plain-copier.md). Continue to [Quickstart](../quickstart.md) or return [Home](../index.md).
