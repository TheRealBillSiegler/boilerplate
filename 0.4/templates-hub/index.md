# Templates hub

Choose a template. See what's available. Jump to deeper docs when you need them.

## Choose a template

| Template        | Extends   | Description                                                  | Docs                                                                                                                                                                                                                       |
| --------------- | --------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`project`**   | —         | A general-purpose Python project, with its tools configured. | [Guide](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/project/index.md)                                                                                                                               |
| **`streamlit`** | `project` | A Streamlit app, built on the general-purpose template.      | [Guide](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/streamlit/index.md) · [Containers](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/streamlit/deployment/containers/index.md) |

List locally: `boilerplate list`

Authoring a custom template? See the [Authoring guide](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/authoring/index.md) and [Composition guide](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/composition/index.md); when a template needs a breaking change, [Versioning and migration](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/versioning/index.md) sets the rules and the [Migration guide template](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/migration-guide-template/index.md) documents it.

## Where next

Most users start with `project`; need a Streamlit app? pick `streamlit`. Exploring custom scaffolds later—read the authoring guide. Composing or updating a project without the CLI? See [compose and update with plain Copier](https://therealbillsiegler.github.io/boilerplate/0.4/templates-hub/plain-copier/index.md). Continue to [Quickstart](https://therealbillsiegler.github.io/boilerplate/0.4/quickstart/index.md) or return [Home](https://therealbillsiegler.github.io/boilerplate/0.4/index.md).
