# CLI

Everything for driving Boilerplate from the command line.

- **[Examples](https://therealbillsiegler.github.io/boilerplate/0.4/cli-examples/index.md)** — copy-pastable commands for common tasks.
- **[Commands](https://therealbillsiegler.github.io/boilerplate/0.4/cli/index.md)** — the full reference for every command, its options, and exit codes (lives in the Reference section).
- **[Customization](https://therealbillsiegler.github.io/boilerplate/0.4/customization/index.md)** — pre-filled answers via a per-user `profile.toml`, extra template layers, or your own wrapper script.
